# Code of Conduct

## Our Pledge

We are committed to providing a friendly, safe, and inclusive environment for all contributors and users of Watchtower, regardless of experience level, gender identity and expression, sexual orientation, disability, personal appearance, body size, race, ethnicity, age, religion, nationality, or other characteristics.

## Our Standards

Examples of behavior that contributes to a positive environment include:

### ✅ Positive Behaviors
- **Being respectful**: Using welcoming and inclusive language
- **Being collaborative**: Focusing on what's best for the community and project
- **Being constructive**: Providing helpful feedback and suggestions
- **Being patient**: Understanding that people have different skill levels and backgrounds
- **Being professional**: Maintaining focus on technical discussions and project goals

### ❌ Unacceptable Behaviors
- Harassment, discrimination, or offensive comments
- Personal attacks or trolling
- Publishing others' private information without permission
- Spamming or excessive self-promotion
- Any conduct that could be considered inappropriate in a professional setting

## Our Responsibilities

Project maintainers are responsible for:
- Clarifying standards of acceptable behavior
- Taking appropriate action in response to unacceptable behavior
- Removing, editing, or rejecting contributions that don't align with this Code of Conduct

## Scope

This Code of Conduct applies to:
- All project spaces (GitHub repository, issues, pull requests, discussions)
- Public representation of the project
- Community events or forums related to the project

## Enforcement

### Reporting
If you experience or witness unacceptable behavior, please report it by:
- Opening a private issue on GitHub
- Contacting project maintainers directly

### Response
All reports will be:
- Reviewed promptly and fairly
- Kept confidential
- Investigated thoroughly
- Responded to appropriately

### Consequences
Unacceptable behavior may result in:
- Warning and guidance
- Temporary restriction from project participation
- Permanent ban from the project community

## Attribution

## Questions?

If you have questions about this Code of Conduct, please create an issue or contact the maintainers.
