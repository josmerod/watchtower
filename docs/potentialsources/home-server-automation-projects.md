## 🚀 Quick Setup Guide

### Unraid Community Templates
Many of these projects already have Unraid Community Applications templates:

1. **Go to Apps → Community Applications**
2. **Search for project name** (e.g., "free-games-claimer")
3. **Click "Install"** and configure variables
4. **Set up schedule** using Unraid's built-in scheduler

### Docker Compose Examples
For projects without Unraid templates, use Docker Compose:

```yaml
version: '3.8'
services:
  free-games-claimer:
    image: vogler/free-games-claimer:latest
    container_name: free-games-claimer
    environment:
      - TZ=America/New_York
      - EPIC_EMAIL=${EPIC_EMAIL}
      - EPIC_PASSWORD=${EPIC_PASSWORD}
      - GOG_EMAIL=${GOG_EMAIL}
      - GOG_PASSWORD=${GOG_PASSWORD}
    volumes:
      - /path/to/config:/config
    restart: unless-stopped
```

## ⚠️ Important Considerations
