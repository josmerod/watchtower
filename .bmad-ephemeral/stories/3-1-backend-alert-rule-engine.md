# Story 3.1: Backend Alert Rule Engine

Status: done

## Story

As a **system**,
I want **a rule engine to evaluate content and trigger alerts**,
so that **users receive notifications for content matching their criteria**.

## Acceptance Criteria

1. **Given** new content is detected by watchers
   **When** the alert engine evaluates the content
   **Then** it checks against all active user alert rules

2. **And** rules support conditions: source_match, keyword_match, category_match, price_threshold

3. **And** matching content generates alert events

4. **And** alert events are stored in `data/alerts/{user_id}/events/`

5. **And** duplicate alerts within 1 hour are suppressed

The alert engine must integrate with existing BaseWatcher framework and preserve the <30-minute source integration capability. Use existing Pydantic patterns and JSON file storage to maintain consistency with current architecture [Source: docs/architecture.md#Decision-Summary].

Key architectural constraints:
- File-based JSON storage for alert events in `data/alerts/{user_id}/events/` [Source: docs/architecture.md#Data-Storage-Patterns]
